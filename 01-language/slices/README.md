# Задача: слайсы

Реализуй дженерик-функции в `task.go`:

| Функция | Требование |
|---------|-----------|
| `Reverse(s)` | разворот на месте, 0 аллокаций |
| `RemoveAt(s, i)` | удалить элемент с сохранением порядка, без новой аллокации; «хвост» обнулить, чтобы GC мог собрать указатели |
| `Chunk(s, size)` | разбить на куски; `append` к куску **не должен** портить соседний кусок (подсказка: `s[lo:hi:max]`) |
| `Dedup(s)` | убрать дубликаты, сохраняя порядок первых вхождений; исходный слайс не менять |

Вопросы, которые зададут на собеседовании:

1. Почему в `RemoveAt` нужно обнулять освободившийся элемент?
2. Что вернёт `Chunk(nil, 3)`? А `Chunk(s, 0)`? Какое поведение разумно?
3. Чем `Dedup` с мапой хуже/лучше сортировки + прохода? (память, порядок, сложность)
