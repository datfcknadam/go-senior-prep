# Задача: алгоритмы для live coding

Шесть функций в `task.go` — условия в комментариях и в [README раздела](..).

Порядок работы над каждой:

1. Проговори условие и граничные случаи.
2. Назови наивное решение и его сложность.
3. Напиши оптимальное за 15–20 минут, **не запуская тесты**.
4. Прогони пример в голове, назови сложность по времени и памяти.
5. Только теперь запусти тесты.

| Функция | Подсказка |
|---|---|
| `IsValidBrackets` | стек |
| `MergeIntervals` | сортировка по началу + один проход |
| `TopKFrequent` | подсчёт + куча размера k (`container/heap`) или bucket sort |
| `GroupAnagrams` | ключ мапы — массив частот `[26]byte` (массивы сравнимы!) |
| `LongestUniqueSubstring` | скользящее окно + последняя позиция руны |
| `MinWindowSum` | два указателя, окно сжимается, пока сумма ≥ target |
