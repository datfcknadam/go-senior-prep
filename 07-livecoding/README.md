# 07. Live coding

Алгоритмическая часть на Go-собеседованиях обычно уровня LeetCode easy/medium, но важно, **как** ты решаешь:

1. Повтори условие своими словами, уточни ограничения и граничные случаи (пустой вход, дубли, отрицательные числа, размер).
2. Озвучь наивное решение и его сложность.
3. Предложи оптимальное, договорись, потом пиши.
4. Пиши чисто: понятные имена, без лишнего.
5. Сам прогони пример и граничные случаи, назови итоговую сложность по времени и памяти.

Молчать 10 минут, а потом выдать код — плохо. Думать вслух — хорошо.

## Задачи

Все в пакете [`algos`](algos), заготовки — в `task.go`.

| Функция | Задача | Целевая сложность |
|---|---|---|
| `IsValidBrackets` | правильная скобочная последовательность `()[]{}` | O(n) |
| `MergeIntervals` | слить пересекающиеся интервалы | O(n log n) |
| `TopKFrequent` | k самых частых элементов | O(n log k) или O(n) |
| `GroupAnagrams` | сгруппировать анаграммы | O(n·m) |
| `LongestUniqueSubstring` | длина самой длинной подстроки без повторов (по рунам) | O(n) — скользящее окно |
| `MinWindowSum` | минимальная длина подмассива с суммой ≥ target (положительные числа) | O(n) — два указателя |

Частые темы, которые стоит прорешать дополнительно: два указателя, скользящее окно, хеш-таблицы, стек,
бинарный поиск, BFS/DFS, куча (`container/heap`), префиксные суммы.
