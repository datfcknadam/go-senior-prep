# Задача: перевод между счетами без дедлока

```go
func Transfer(from, to *Account, amount int64) error
```

Наивная версия:

```go
from.mu.Lock()
to.mu.Lock()
```

Горутина 1 переводит A → B, горутина 2 — B → A. Первая взяла A и ждёт B, вторая взяла B и ждёт A — **дедлок**.

Требования:

- Атомарность: нет момента, когда деньги списаны с одного счёта, но не зачислены на другой (с точки зрения `Balance` всех счетов под блокировкой).
- Недостаточно средств → `ErrInsufficientFunds`, балансы не меняются.
- `from == to` → `ErrSameAccount`.
- Никаких дедлоков при любом порядке аргументов.
