# Задача: Merge (fan-in)

```go
func Merge[T any](ctx context.Context, chans ...<-chan T) <-chan T
```

- Читает из всех входных каналов и пишет в один выходной.
- Выходной канал закрывается, когда закрыты **все** входные **или** отменён `ctx`.
- После отмены `ctx` не должно оставаться висящих горутин, даже если никто не читает выход.
- `Merge(ctx)` без каналов возвращает сразу закрытый канал.

Частое продолжение на собеседовании: «а теперь сделай без горутины на каждый канал» (`reflect.Select`)
и «как сохранить порядок» (никак без доп. информации — обсуди, зачем он вообще нужен).
