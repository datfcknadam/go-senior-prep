# Задача: singleflight

Сценарий: популярное объявление выпало из кэша, и 10 000 запросов одновременно идут в базу за одной и той же записью
(**cache stampede / thundering herd**). Нужно, чтобы в базу пошёл один запрос, а остальные дождались его результата.

```go
var g Group[string, Ad]
ad, err, shared := g.Do(key, func() (Ad, error) { return db.Load(key) })
```

- Пока для `key` выполняется вызов, новые вызовы `Do` с тем же ключом не запускают `fn`, а ждут и получают тот же результат.
- `shared == true`, если результат достался больше чем одному вызывающему.
- После завершения ключ забывается: следующий `Do` снова вызовет `fn`.
- Разные ключи не блокируют друг друга.
- Нулевое значение `Group` готово к работе.

Вопросы:

- Что будет, если `fn` запаникует? Что в этом случае делает `x/sync/singleflight`?
- Что будет, если `fn` повиснет? Как это связано с контекстом первого вызывающего? (`DoChan`, `context.WithoutCancel`)
- Какие ещё способы борьбы со stampede ты знаешь? (probabilistic early expiration / XFetch, lock в Redis, stale-while-revalidate)
