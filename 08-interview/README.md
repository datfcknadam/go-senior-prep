# 08. Собеседование

## Как обычно проходит процесс

Точный порядок зависит от команды — уточни у рекрутера на первом звонке, это нормальный вопрос. Типичная схема для senior:

1. **Скрининг с рекрутером** — опыт, мотивация, ожидания по деньгам и формату.
2. **Техническое интервью** — Go вглубь (рантайм, конкурентность), live coding, разбор кода «найди проблемы», базы данных.
3. **System design** — один кейс на 60 минут.
4. **Финал с командой / руководителем** — опыт, проекты, поведенческие вопросы, вопросы к команде.

Спроси у рекрутера: какие этапы, сколько длится каждый, где писать код (IDE, онлайн-редактор), можно ли запускать.
