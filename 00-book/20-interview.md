## 2. Как отвечать на теоретический вопрос

Схема: **структура → операция → почему так → следствие для кода**. Если интервьюер копает глубже, у тебя есть следующий уровень.

Плохо: «мапа — хеш-таблица, порядок случайный».

Хорошо: «С 1.24 мапа — Swiss table: группы по 8 слотов с контрольным словом из 7-битных фрагментов хеша. Поиск сравнивает 8 байт разом
и трогает ключ только при совпадении, поэтому меньше кеш-промахов. Таблицы ограничены 1024 слотами и делятся при росте, так что латентность вставки ограничена.
Адрес элемента взять нельзя, потому что слоты переезжают, а порядок обхода рандомизирован специально, чтобы на него не полагались».

Ещё приёмы:
- Называй версию Go, если поведение менялось (переменные цикла 1.22, мапы 1.24, GOMAXPROCS 1.25).
- Связывай с продакшном: «поэтому в нашем сервисе мы…».
- «Не знаю, но рассуждал бы так…» лучше уверенной выдумки.

## 3. Как вести себя на live coding

1. Уточни требования и граничные случаи вслух (пустой вход, отмена, ошибка в середине, порядок результатов).
2. Скажи план и сложность до кода.
3. Пиши простую корректную версию, потом улучшай.
4. Для конкурентного кода сам проговори: кто закрывает каналы, как завершается каждая горутина, где happens-before, что будет при отмене.
5. Предложи тесты: какие случаи и как проверить отсутствие гонок (`-race`) и утечек (`goleak`).

## Закрепление

Упражнения запускаются прямо в панели (`make panel`, эта глава): правь код в редакторе и жми ▶ или <kbd>⌘/Ctrl+Enter</kbd>. Упражнение засчитывается, когда вывод совпал с ожидаемым; конкурентные прогоняются с `-race`. Подсказки открываются по одной — сначала попробуй без них.

```go
// exercise: RLE за 10 минут
// expect: "a3bc2d4"
// expect: "ж2и"
// expect: ""
// hint: Работай с рунами, а не байтами: "жжи" в байтах — шесть элементов.
// hint: Держи текущую руну и счётчик; при смене руны (и после цикла) сбрасывай их в strings.Builder. Счётчик 1 не пишется.
package main

import "fmt"

// compress сжимает подряд идущие символы: "aaab" → "a3b".
func compress(s string) string {
	panic("TODO")
}

func main() {
	for _, s := range []string{"aaabccdddd", "жжи", ""} {
		fmt.Printf("%q\n", compress(s))
	}
}
```

```go
// exercise: Скользящее окно
// expect: 3 3 2 0
// expect: stored: 0
// hint: Храни время хитов по возрастанию. Count(now) сначала выкидывает всё, что старше now - window, затем возвращает длину.
// hint: Удаление с головы — w.hits = w.hits[n:]; найти n можно циклом или sort.Search. Почему без чистки нельзя на проде?
package main

import (
	"fmt"
	"time"
)

// Window считает события за последние size: интервал (now-size, now].
type Window struct {
	size time.Duration
	hits []time.Time
}

func (w *Window) Hit(t time.Time)         { panic("TODO") }
func (w *Window) Count(now time.Time) int { panic("TODO") }

func main() {
	t0 := time.Date(2026, 1, 1, 0, 0, 0, 0, time.UTC)
	sec := func(s int) time.Time { return t0.Add(time.Duration(s) * time.Second) }
	w := &Window{size: time.Minute}
	for _, s := range []int{0, 10, 30} {
		w.Hit(sec(s))
	}
	a := w.Count(sec(30))
	w.Hit(sec(65))
	b := w.Count(sec(65))
	c := w.Count(sec(75))
	d := w.Count(sec(200))
	fmt.Println(a, b, c, d)
	fmt.Println("stored:", len(w.hits))
}
```
